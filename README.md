# hxyfront-62004 雪板调校工位派发台

面向滑雪板调校店的工位派发前端，预置工单、技师和工位（数据仅存浏览器 localStorage）。

## 业务规则

- 工单记录：品牌、长度、板型、侧/底刃角、蜡型、底板损伤、修补位置、客户偏好、预估工时。
- 派发校验（任一不通过即**整单拒绝**，队列与工位占用保持不变）：
  - 工位未被其他施工中工单占用；
  - 已登记底板损伤时必须填写修补位置；
  - 技师当日余时 ≥ 工单预估工时；
  - 蜡型符合工位温区（低温蜡→低温区、暖温蜡→暖温区、全温蜡通用）。
- 派发成功：工单进入施工中，占用工位并扣减技师余时。
- 派发后修改底板损伤/修补位置/刃角：**立即撤单**，释放工位并返还技师余时。
- 已完工工单**只读**；完工筛选、工位负载、客户历史均与当前数据同步。

## 文件划分

- `src/rules.ts`：规则（领域模型、派发校验、撤单/完工状态流转、统计选择器）。
- `src/storage.ts`：存储（localStorage 读写、预置数据、重置）。
- `src/App.tsx`：界面（队列、筛选、工位负载、技师余时、客户历史）。
